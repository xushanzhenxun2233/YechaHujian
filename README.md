# 夜叉护笺 (YechaHujian) — Android 原生病例存储与用药管理 App

基于 **Kotlin + Jetpack Compose + Material 3 + Room + Coil** 开发的纯本地、注重医疗隐私的 Android 原生应用（包名：`com.yechahujian.app`）。

## 核心功能

1. **病例相册（系统相机/相册 + 平铺浏览 + 图文绑定自由排序 + 长按保存/分享）**
   - 支持调用系统相机拍照或从系统相册批量导入照片，自动保存至应用私有安全存储目录。
   - 支持 2 列 / 3 列平铺视图切换、分类筛选（病历/化验单/处方/影像/费用清单/其他）与备注关键词搜索。
   - **图文强绑定与自由调换位置**：每张照片与其自定义文字备注、分类作为同一实体绑定；长按卡片拖拽或开启「排序模式」调整顺序时，照片与备注始终同步移动并实时持久化。
   - **长按保存到手机与系统分享**：点击卡片全屏双指缩放查看，长按图片或点击顶部图标即可保存到手机系统相册（`Pictures/夜叉护笺`）或调用系统分享（微信/QQ 等）。

2. **开药统计与服药剂量打卡**
   - 支持拍照保存药盒或从相册选图（点击药盒图片同样支持全屏放大、长按保存与分享），记录药品单价、购买数量、每次服用剂量、每日服用次数与服药时间提示。
   - 自动统计本月开药花费与累计开药总花费。
   - 支持按日期（含最近 7 天回溯）逐次打卡或一键打卡，实时展示当日服药完成率。

3. **医保报销计算器（GPS 自动推断 + 自定义参数）**
   - 支持调用手机 GPS / 网络定位，结合系统地理编码与离线坐标匹配算法，自动推断所在省市并加载当地职工/居民、门诊/住院、一二三级医院参考报销政策。
   - 支持手动切换地区，以及在「调参数」中自由微调起付线、报销比例、年度封顶线、乙类先行自付比例。
   - 支持一键带入累计开药费用，实时输出医保报销金额、个人自付总额及明细构成。

4. **全量数据跨设备迁移（本地 ZIP 备份包）**
   - 一键导出完整 `.zip` 备份包（含 `manifest.json`、`data.json`、全部病例照片与药品照片）。
   - 通过微信/蓝牙/手机互传发送到新设备后，一键选择 `.zip` 恢复（支持「覆盖恢复」与「合并导入」两种模式）。

## 构建与运行

- **Android Studio**: 直接打开项目根目录，等待 Gradle 同步完成后点击 Run 即可安装到真机或模拟器（`minSdk = 26`, `compileSdk = 34`）。
- **命令行构建**:
  ```bash
  ./gradlew assembleDebug
  ./gradlew testDebugUnitTest
  ```
- **直接下载安装包**: 可在本仓库 [Releases](../../releases) 页面下载 `夜叉护笺-v1.0.0.apk`。
